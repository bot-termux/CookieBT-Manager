# CookieBT Manager

Professional browser cookie manager for importing, exporting, editing, filtering, and restoring website sessions.

---

## Features

- Import / export cookies
- Edit cookies directly
- Restore website sessions
- Support multiple formats:
  - JSON
  - Cookie Header
  - Netscape cookies.txt
  - name=value
- Current website focused mode
- Advanced mode for all browser cookies

---

## Installation

### Manual Installation

1. Download or extract the extension folder

2. Open Chrome Extensions page:

```text
chrome://extensions
```

3. Enable:

```text
Developer mode
```

4. Click:

```text
Load unpacked
```

5. Select the extension folder

Done.

---

## Privacy Statement

CookieBT Manager does not collect, transmit, store, or share any user data remotely.

All cookie processing happens locally inside the user's browser.

No analytics, tracking, telemetry, or external servers are used.
